## A · 커서 K (추천)
- 세로획 = 검색창의 커서 / 위로 뻗는 팔(Ice) = 성장 그래프 / 아래 다리 = 실행과 측정
- 100×100 그리드, 세로획 11 · 팔 10.6(시각 보정), 성장 각도 49.4°, 모서리 rx 22
- 색: Master Blue #2340E0 · Ice #A9BBFF · Ink #0A1024 · Deep #121A33 · Stone #EDEEEA

## 파일
| 파일 | 용도 |
|---|---|
| `svg/A-symbol-blue.svg` | 기본 심볼 · 파비콘 · 앱/SNS 프로필 |
| `svg/A-symbol-ink.svg`, `A-symbol-light.svg` | 어두운/밝은 배경용 심볼 |
| `svg/A-symbol-animated.svg` | 커서 깜빡임 → 성장선이 솟는 애니메이션 (로딩·인트로용) |
| `svg/A-lockup-light.svg`, `A-lockup-dark.svg` | 영문 가로형 (웹 헤더·제안서) |
| `svg/A-lockup-ko-light.svg`, `A-lockup-ko-dark.svg` | 한글 주표기 가로형 (명함·현수막·오프라인) |
| `svg/A-wordmark-*.svg` | 워드마크 단독 |
| `svg/B-*`, `svg/C-*` | 대안 B(검색 렌즈) · C(선택된 키워드) |
| `png/` | A안 PNG 내보내기 (심볼 1024/512/180/32, 가로형 240px 높이) |
| `generate.py` | 생성 스크립트 (Pretendard 700/800/900 정적 인스턴스 필요) |

모든 글자는 Pretendard를 외곽선(path)으로 변환해, 글꼴이 없는 환경에서도 같은 모양으로 보입니다.
